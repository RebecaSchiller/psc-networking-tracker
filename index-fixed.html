How it works

Takes about 10 minutes to set up. Nothing to install.

Network Momentum connects to a Google Sheet you control. Your data never touches our servers. Setup requires a desktop or laptop — Google Sheets extensions are not available on mobile or tablet.

1

Create a Google Sheet

Go to sheets.google.com, create a blank spreadsheet, and rename the first tab to Contacts.

2

Add the Apps Script

Paste a small script that bridges the app and your sheet. Follow the full setup guide: Mac or Windows.

3

Connect and go

Paste your Web App URL. Then add your AI API key to unlock AI-powered suggestions. Network Momentum works with Anthropic (Claude) by default. Prefer OpenAI? You can use your own OpenAI API key instead. Get one at platform.openai.com. The API is a separate product from Claude.ai and ChatGPT. It is billed per use regardless of any existing subscription.

4

Start tracking

Add your first contact, set a weekly goal, and let the app help you stay consistent.

FAQ

Common questions.

Does Network Momentum cost anything?

The app itself has no subscription, no account, and no data stored on our servers. Your contacts live in your own Google Sheet. AI features require your own API key and are billed per use directly by your provider, either Anthropic or OpenAI. For light personal use, costs are minimal, typically a few cents a month.

Do I need an AI API key?

Only if you want AI-powered features like next-step suggestions and company dossiers. Without a key, the rest of the app (contact tracking, pipeline view, email templates, and weekly planning) works just fine.

Which AI providers does Network Momentum support?

Network Momentum is built with Anthropic's Claude as the default AI provider. If you already have an OpenAI account and prefer to use that instead, you can use your own OpenAI API key. Either way, you connect your key directly inside the app.

Does my ChatGPT subscription give me API access?

No. A ChatGPT Plus (or any ChatGPT) subscription is a separate product from OpenAI's API and does not include API access. To use OpenAI's API with Network Momentum, you need a separate OpenAI platform account with its own billing. Create one at platform.openai.com. You pay OpenAI directly based on usage, with no fixed monthly fee.

Who pays for the AI usage?

You do, directly to whichever AI provider you choose. Network Momentum never touches your API key billing. For most users, the cost is minimal, just a few cents per month at typical networking volumes.

Is my data private?

Yes. Your contact data never touches our servers. Everything is stored in a Google Sheet you own and control. The only external calls made are to whichever AI provider you've connected, using your own API key.
