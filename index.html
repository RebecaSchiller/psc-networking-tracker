Create a Google Sheet
Go to sheets.google.com, create a blank sheet, rename the first tab to Contacts.
2
Add the Apps Script
Click Extensions > Apps Script, delete all existing code, paste in the script from your Code.gs file, and save.
3
Deploy as a Web App
Click Deploy > New deployment. Set type to Web app, Execute as Me, Who has access Anyone. Deploy and authorize.
