Network Momentum

Setup Guide — Getting your Google Sheet connected

Network Momentum stores your contacts in your own Google Sheet — nothing goes to any server. This guide walks you through the one-time setup in about 10 minutes.
3 Steps total
~10 Minutes
1× Done once, works forever
1

Create your Google Sheet

This is where your contacts will be stored

You need a Google account for this step. If you have Gmail, you're already set.

1

Go to sheets.google.com and sign in.

2

Click the + button (Blank spreadsheet) to create a new sheet.

3

At the top of the page, click Untitled spreadsheet and rename it to something like Network Momentum Contacts.

4

At the bottom of the screen, you'll see a tab named Sheet1. Double-click it and rename it exactly: Contacts — capital C, no spaces.

⚠️ The tab name must be exactly Contacts — if it's spelled differently, the app won't be able to read your data.
2

Add the Apps Script

This is the bridge between the app and your sheet

Google Apps Script connects Network Momentum to your spreadsheet. You'll paste a script and deploy it as a Web App.

1

In your Google Sheet, click Extensions in the top menu bar, then click Apps Script.

2

A new browser tab opens with a code editor. You'll see some starter code. Select all of it and delete it.

3

Copy the entire script below and paste it into the editor:

function doGet(e) { var action = e.parameter.action; var ss = SpreadsheetApp.getActiveSpreadsheet(); var sheet = ss.getSheetByName("Contacts"); if (action === "headers") { var headers = sheet.getRange(1, 1, 1, sheet.getLastColumn()).getValues()[0]; return ContentService.createTextOutput(JSON.stringify({ headers: headers })) .setMimeType(ContentService.MimeType.JSON); } if (action === "read") { var data = sheet.getDataRange().getValues(); return ContentService.createTextOutput(JSON.stringify({ rows: data })) .setMimeType(ContentService.MimeType.JSON); } if (action === "append") { var row = JSON.parse(e.parameter.row); sheet.appendRow(row); return ContentService.createTextOutput(JSON.stringify({ status: "ok" })) .setMimeType(ContentService.MimeType.JSON); } if (action === "update") { var rowIndex = parseInt(e.parameter.rowIndex); var row = JSON.parse(e.parameter.row); sheet.getRange(rowIndex, 1, 1, row.length).setValues([row]); return ContentService.createTextOutput(JSON.stringify({ status: "ok" })) .setMimeType(ContentService.MimeType.JSON); } if (action === "clear") { var rowIndex = parseInt(e.parameter.rowIndex); var numCols = sheet.getLastColumn(); sheet.getRange(rowIndex, 1, 1, numCols).clearContent(); return ContentService.createTextOutput(JSON.stringify({ status: "ok" })) .setMimeType(ContentService.MimeType.JSON); } return ContentService.createTextOutput(JSON.stringify({ error: "Unknown action" })) .setMimeType(ContentService.MimeType.JSON); }
4

Click the Save icon (or press Ctrl+S / Cmd+S) to save the script.

✓ The script name at the top doesn't matter — you can leave it as "Untitled project" or rename it to "Network Momentum."
3

Deploy as a Web App

This generates the URL you'll paste into Network Momentum

Deploying the script creates a secure URL that lets Network Momentum talk to your sheet.

1

In the Apps Script editor, click the blue Deploy button in the top right corner, then select New deployment.

2

In the dialog that opens, click the gear icon next to "Select type" and choose Web app.

3

Fill in the settings exactly as follows:

Description Network Momentum (or anything you like) Execute as Me (your Google account) Who has access Anyone
⚠️ "Who has access" must be set to Anyone — if it's set to "Only myself," the app won't be able to connect to your sheet.
4

Click Deploy. Google will ask you to authorize the script.

5

Click Authorize access. A browser window opens. Choose your Google account, then click Advanced → Go to [project name] (unsafe) → Allow.

ℹ️ The "unsafe" warning is Google's standard caution for any script you write yourself — it's not actually unsafe. You wrote (or pasted) this script, and it only accesses your own spreadsheet.
6

After authorizing, you'll see a Web app URL. It looks like:
https://script.google.com/macros/s/ABC.../exec
Copy this URL. You'll need it in the next step.

✓ Paste the URL somewhere safe like a notes app — if you lose it, you can always find it again under Deploy → Manage deployments in the Apps Script editor.
4

Connect to Network Momentum

Paste your Web App URL into the app
1

Go to networkmomentum.app and click Get Started (or Open App).

2

On the setup screen, paste the Web App URL you copied in Step 3 into the Google Apps Script URL field.

3

Click Connect. The app will verify the connection to your sheet.

4

If the connection succeeds, you'll land on your contacts dashboard. You're ready to go.

⚠️ If you get a connection error, double-check that "Who has access" is set to Anyone in your deployment settings, and that you copied the full URL including the /exec at the end.

You're all set

Your contacts are stored privately in your own Google Sheet.
Network Momentum never stores your data on any external server.
